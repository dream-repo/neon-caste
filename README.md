# NEON CASTE – Part 1: The Gutter

A dystopian cyberpunk side-view brawler RPG that runs in the browser. Play: https://dream-repo.github.io/neon-caste/

- Climb from **Hobo** to **Citizen** (Warrior, Elite and Ruler are data-driven for later parts).
- Melee (light / heavy / dodge / block), auto-aim gun with crafted ammo, one implant power, and a Humanity stat.
- Loot rarities, a crafting bench with 3 mod slots per weapon, the Fence and the Ripperdoc, STREET / IRON / GHOST skill trees, and perks at rank-up.
- Story with Mama Ox, Dex, Doc Iris and your rival Nero, plus the Proof choice.

Phone first (touch d-pad and action buttons). Keys: WASD/arrows move, J light, K heavy, L block, Space dodge, I shoot, U power, Esc menu.

Plain HTML + JS, no build step. Painted portraits, fight sprites and district backdrops live in `assets/` (shape placeholders are the fallback if an image fails to load). All dialogue lives in `story.js`.
